
# JavaScript Fundamentals

A collection of practical JavaScript exercises focused on programming fundamentals, logical thinking, and problem-solving.

## Technologies

- JavaScript (ES6+)
- Node.js
- Git & GitHub

## Projects

| File | Description |
|------|-------------|
| `calculator.js` | Basic calculator with arithmetic operations |
| `getSeason.js` | Determines the season based on the month |
| `addNumber.js` | Array operations and number analysis |
| `randomPasswords.js` | Random password generator |
| `calculateAverage.js` | Calculates the average of numbers |
| `rockPaperScissors.js` | Rock, Paper, Scissors game |
| `flightSystem.js` | Flight management and booking logic |

## Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/).

### Run an Exercise

Clone the repository:

```bash
git clone https://github.com/labkramar-jpg/javascript-fundamentals.git
cd javascript-fundamentals
```

Run an exercise using Node.js:

```bash
node calculator.js
```

Replace `calculator.js` with another filename to run a different exercise.

## Learning Objectives

- Working with variables and data types
- Using conditional statements and loops
- Writing reusable functions
- Manipulating arrays
- Implementing basic algorithms
- Practicing JavaScript problem-solving
